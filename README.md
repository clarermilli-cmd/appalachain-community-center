# Appalachian Community Center

React + Vite frontend with an AWS Amplify Gen 2 backend. The frontend uses Amplify Auth for administrator sign-in, Amplify Data for event records, and Amplify Storage for event photos.

## Requirements

- Node.js 20 or later (use the version supported by the current AWS Amplify Hosting build image)
- npm
- Access to the AWS account and Amplify app that own this project's backend

## Frontend setup

```bash
cd frontend
npm ci
```

The app imports `frontend/amplify_outputs.json`. This file is generated by Amplify and intentionally is not committed. For local development, run an Amplify sandbox using an AWS-authenticated developer account:

```bash
npx ampx sandbox
```

Keep the sandbox running in its terminal, then in a second terminal run:

```bash
npm run dev
```

To build the frontend, make sure a valid `amplify_outputs.json` has been generated first:

```bash
npm run build
```

## Deployment

The root `amplify.yml` runs `ampx pipeline-deploy` for the current Amplify branch, then builds the Vite frontend from `frontend/` and publishes `frontend/dist/`. Deploy through the existing AWS Amplify app and confirm its branch is connected to the correct AWS account and backend environment.

## Administrator access

Self-service sign-up is disabled. An AWS administrator must create administrator users in the Cognito user pool. Do not add public sign-up unless the access model is deliberately redesigned.

## Events

The administrator dashboard at `/admin` manages Amplify Data event records and uploads event photos to Amplify Storage. The public `/events` page currently contains the Art Connect Slime Workshop flyer as a static event announcement; it is not yet driven by the admin dashboard.

## Important project notes

- The `backend/` directory is a legacy Express/SQLite implementation and is not used by the current Amplify frontend/deployment flow. AWS Amplify Hosting does not automatically deploy that Express server.
- Do not commit `.env` files, local database files, uploads, `node_modules`, or generated Amplify outputs.
- The contact form is not connected to a delivery service yet. It must not display a success message until real delivery is implemented.
- Review placeholder program descriptions, operating hours, testimonials, statistics, and organization contact details before publishing them as factual information.
